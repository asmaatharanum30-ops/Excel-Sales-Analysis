# Excel Sales Data Analysis

## Project Overview
This is a personal data analysis project using Microsoft Excel to explore and analyse sales data.

## Tools & Skills Used
- Microsoft Excel
- Pivot Tables
- VLOOKUP and XLOOKUP
- IF, SUMIF and COUNTIF
- Data Cleaning
- Charts and Data Visualisation
- Conditional Formatting

## Project Objectives
- Organise and analyse sales data.
- Summarise sales information using Pivot Tables.
- Identify sales trends and patterns.
- Present data through charts and visual dashboards.

## Key Learning Outcomes
- Improved practical Excel skills.
- Developed data analysis and reporting skills.
- Gained experience presenting information in a structured format.
